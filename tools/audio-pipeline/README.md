# Audio Pipeline

Licensed acquisition, processing, and publishing pipeline for game audio of
*The Name of the Wind: The Kingkiller Chronicle* (unofficial fan game,
Godot 4.7). Sister tool to `tools/lpc-factory/`.

```
DOWNLOAD -> SOURCE ARCHIVE -> LICENSE VALIDATION -> CANDIDATE ->
PROCESS -> AUDIO REVIEW -> PUBLISH -> GAME ASSETS
```

## Layout

```text
tools/audio-pipeline/
├── sources/original/    immutable downloads + synthesis outputs (never edit)
├── sources/licenses/    per-asset license evidence (<id>.json)
├── candidates/          approved | review-required | rejected (+ reports)
├── processed/           game-ready encodes keyed by asset id
├── metadata/
│   ├── requirements.json  authored catalog of logical audio IDs to fill
│   ├── licenses.json      authored registry: provenance + license + review state
│   └── audio-index.json   generated by index-audio.mjs
└── scripts/
    ├── index-audio.mjs      validate registry <-> files, build audio-index.json
    ├── validate-license.mjs enforce the license tier policy
    ├── normalize-audio.mjs  FFmpeg loudness/format normalization -> OGG
    ├── publish-audio.mjs    copy approved files into audio/, emit manifest
    └── generate-credits.mjs emit CREDITS/AUDIO-CREDITS.txt + .csv
```

Production audio lives in the repo-root `audio/` tree (this project keeps
top-level category dirs: `art/`, `audio/`, `maps/`, `data/`), organized by
gameplay event:

```text
audio/
├── music/{menu,ruh,tarbean,university,imre,underthing,chandrian,combat,travel,emotional}/
├── ambience/{forest,city,tarbean,university,archives,underthing,tavern,weather,fire,crowd}/
├── sfx/{combat,weapons,footsteps,clothing,doors,objects,books,coins,ui,sympathy,naming,animals,environment}/
└── instruments/lute/
```

`publish-audio.mjs` generates `audio/audio-manifest.json`, mapping logical
event IDs (`SFX_PAGE_TURN`, `MUS_UNIVERSITY_DAY`, `AMB_TARBEAN_NIGHT`) to
variant file lists. Gameplay code plays events through the `AudioLibrary`
autoload and must never hardcode file paths — assets can be replaced later
without touching gameplay code.

## Usage

```sh
cd tools/audio-pipeline
npm test                                # pipeline unit tests
npm run audio:index                     # validate + regenerate audio-index.json
npm run audio:validate                  # license tier policy check
npm run audio:normalize -- --all        # FFmpeg -> processed/ (--id <id> for one)
npm run audio:publish                   # approved files -> audio/ + manifest
npm run audio:credits                   # CREDITS/AUDIO-CREDITS.txt + .csv
```

FFmpeg must be on PATH (`ffmpeg -version`); scripts fail with a clear report
when it is missing and never install system packages themselves.

## Approved sources & license rules

Preference order: OpenGameArt CC0 → Freesound CC0 → Pixabay → OpenGameArt
CC-BY → Freesound CC-BY → review-required bucket.

- **CC0** — preferred; still record creator/source/date.
- **CC-BY** — allowed when author + source URL are clear; attribution is
  stored and auto-emitted into credits.
- **CC-BY-SA / OGA-BY / GPL-linked / custom site licenses** — park in
  `candidates/review-required/`; never auto-publish.
- **CC-BY-NC / NC-only / ND / "personal use only" / unclear / unknown** —
  reject (`LICENSE UNKNOWN` when terms cannot be confirmed from the asset
  page itself).
- Never use ripped game/movie/TV/audiobook/soundtrack recordings or
  YouTube/Spotify rips; never search by IP names ("Chandrian theme") — search
  by mood, environment, instrumentation, gameplay purpose instead.
- Music publishes as `review.status: pending` and stays out of the shipped
  soundtrack until explicitly approved; signature SFX (sympathy, Naming,
  Chandrian, lute performances) require approval too.

Full ground rules for agents: [AGENTS.md](AGENTS.md).

## Processing notes

- FFmpeg does repeatable, non-destructive processing; originals are preserved
  byte-for-byte in `sources/original/`.
- Prefer lossless sources (WAV/FLAC); avoid MP3→OGG transcoding chains.
- Runtime format: OGG Vorbis q5 for music/ambience/SFX; very short
  latency-critical effects may stay WAV if profiling demands it.
- Loudness is normalized per category (music/ambience/combat/movement/ui/
  magic) with dynamics preserved, no clipping; only *accidental* silence is
  trimmed — attack tails, reverb, ambience decay are kept.
- Loopable ambience targets 30–180 s and is checked for boundary clicks,
  abrupt changes, and obvious repeating events before publishing.
